# 🗺️ Bloodcat Map

Удобный и быстрый скрипт на Python для визуализации географических координат. Инструмент автоматически принимает координаты и превращает их в красивую, интерактивную HTML-карту, которую можно открыть в любом браузере. Отлично подходит для OSINT-расследований и анализа геолокации.

## 🚀 Функционал
* Быстрое развертывание интерактивной карты по заданным координатам.
* Автоматическое сохранение результата в автономный HTML-файл.
* Удобный интерфейс для работы в терминале.

## 📋 Требования к операционной системе
Программа полностью кроссплатформенная и работает на:
* 📱 Android (через приложение Termux)
* 🐧 Linux (включая Kali Linux)
* 💻 Unix / Windows

## 🛠️ Установка и запуск

1. Склонируйте репозиторий к себе на устройство:
git clone https://github.com/b5ediifgf/bloodcat_map.git
cd bloodcat_map

2. Установите необходимую библиотеку для работы с картами:
pip install folium --break-system-packages

3. Запустите программу:
python3 bloodcat_map.py
